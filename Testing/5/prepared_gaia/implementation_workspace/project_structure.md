# Project Structure

## Main Components

1. `agents/` - All agent implementations
   - `person_in_need.py` - PersonInNeedAgent
   - `helper.py` - HelperAgent
   - `data_handler.py` - DataHandlerAgent
   - `notifier.py` - NotifierAgent
   - `route_planner.py` - RoutePlannerAgent
   - `truck_driver.py` - TruckDriverAgent
   - `services.py` - ServicesAgent

2. `core/` - Core system components
   - `database.py` - Database management
   - `message_types.py` - Message and data structure definitions
   - `protocols.py` - Protocol definitions

3. `utils/` - Utility functions
   - `logger.py` - Logging utilities

4. `run_system.py` - Main entrypoint to start the system

5. `requirements.txt` - Dependencies

6. `README.md` - Documentation
